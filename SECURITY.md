# Security policy

## Supported version

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Do not open a public issue for credentials, code-execution vulnerabilities, or
other sensitive reports. Use GitHub's private vulnerability reporting feature on
the repository Security page.

This research package does not connect to brokers or execute orders. Please treat
any future change that adds external data, secrets, or order execution as a new
security boundary requiring explicit review.
